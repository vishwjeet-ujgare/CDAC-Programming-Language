 Question 5 : Solve any 3 linear equation of your choice using Gauss Elimination method.
 
1) FIRST EQUATION:                                         
                                                          
 x + y + z = 2                                           
 x + 2y + 3z = 5
 x + 2y + 3z = 5
 2x + 3y + 4z = 11
 

STEP 1:

  1  1  1 | 2
  1  2  3 | 5
  2  3  4 | 11
  
STEP 2:

  1  1  1 | 2
  0  1  2 | 3
  2  3  4 | 11
  
STEP 3:

  1  1  1 | 2
  0  1  2 | 3
  0  1  2 | 7
  
  
STEP 4:

  1  1  1 | 2
  0  1  2 | 3
  0  0  0 | 4

STEP 4:
  1  1  1 | 2
  0  1  2 | 3
  0  0  0 | 1
  
  x – z = -1
  y + 2z = 3
  0 = 4
